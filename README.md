Dashboard de Gestión de Proyectos - Next Data
Este proyecto forma parte de mi portafolio de análisis de datos, enfocado en la automatización y visualización del seguimiento de proyectos. El objetivo principal fue centralizar la información de costos y tareas para mejorar la visibilidad del avance y la salud presupuestaria.

🛠 Tecnologías Utilizadas
Power BI Desktop: Herramienta principal para el desarrollo del informe.

DAX (Data Analysis Expressions): Creación de medidas personalizadas (Total_Gasto_Real).

Modelado de Datos: Estructura en esquema de estrella (Star Schema) para una mejor optimización.

Microsoft Excel: Fuente de datos original.

🚀 Características Principales
Análisis de Costos: Seguimiento de la ejecución presupuestaria mes a mes mediante un gráfico de áreas, permitiendo identificar variaciones temporales.

Gestión de Tareas: Visualización del estado actual del proyecto (Completadas, En Progreso, Atrasadas) mediante un gráfico de anillos para una lectura rápida del desempeño del equipo.

Diseño Profesional: Interfaz limpia orientada a la toma de decisiones ejecutivas.
